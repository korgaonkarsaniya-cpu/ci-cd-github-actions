# Dockerized Web Application

## 📌 Project Description

This project demonstrates how to containerize a Flask web application using Docker.

The application runs inside a Docker container and can be accessed through a web browser.

## 🛠️ Technologies Used

- Python
- Flask
- Docker
- Dockerfile
- Git
